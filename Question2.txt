Question Title: Create a Project Folder Structure
Question Link: https://my.newtonschool.co/playground/code/jipp2htnvrww?lecture_hash=v210chxjexei



Solution:

cat > create-service << 'EOF'
#!/bin/bash
mkdir -p service/controllers
mkdir -p service/models
mkdir -p service/routes
mkdir -p service/middleware
echo "API Service" > service/README.md
echo 'console.log("Server started");' > service/server.js
EOF
chmod +x create-service
./create-service



Approach:

First we start to input lines of text into create-service till we read "EOF" and use shebang operator #!/bin/bash for bash code
Secondly we input the services we would liek to happen which is the creator of controllers,models,routes and middleware inside of service which is laso created on the spot using mkdir -p (-p lets us make the non-existing parent folders while declaring the child folder itself)
Next we input the text "API Service" inside of service/README.md replacing all text pre-existing if any and then we put console.log("Server started"); inside of service/server.js
Finally we give the create-service executable permitions and execute it using ./create-service which would in return create all the services and put the text inside of README.md and put the line of code inside of server.js 
If server.js were to be executed , it would output the text "Server started" in terminal (output window) as its inside the printing / writing function of javascript.


Final structure should look like this:
service/
├── controllers/
├── models/
├── routes/
├── middleware/
├── server.js
└── README.md

Result: As a result the create-service command has been fixed and can now generate the required project folder structure with all the necessary files and folders.
