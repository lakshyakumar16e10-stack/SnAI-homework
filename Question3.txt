Question Title: Data Breach Response
Question Link: https://my.newtonschool.co/playground/code/orlr84xpc3oo?lecture_hash=vifkrugjcwth



Solution:

cd breach_response
cp evidence/log_dump.txt log_dump.txt
chmod 755 evidence
mv evidence secure/evidence
chmod 555 secure/evidence
chmod 644 reports/incident_summary.txt
echo "Breach confirmed" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt
echo "Forensics Complete" > secure/forensics_report.txt
chmod 600 secure/forensics_report.txt
chmod 644 reports/incident_summary.txt
echo "Escalated to security team" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt



Approach:

First, we have to enter the breach_response folder using cd.
Secondly, we copy log_dump.txt from the evidence folder into the breach_response folder using cp.
Then we have to temporarily change the permission of the evidence folder from 555 to 755 using chmod so that we can move it.
After that, we move the evidence folder inside the secure folder using mv and restore its permission back to 555.
Next, we have to change the permission of incident_summary.txt from 444 to 644 so that we can edit it.
We use echo with >> to append "Breach confirmed" to incident_summary.txt and then restore its permission to 444.
Then we create a new file named forensics_report.txt inside the secure folder using echo and write "Forensics Complete" into it.
We use chmod 600 to make sure that only the owner can read and write the forensics report.
After that, we again change the permission of incident_summary.txt to 644 and append "Escalated to security team" using echo with >>.
Finally, we restore the permission of incident_summary.txt back to 444 and leave classified.txt unchanged with permission 000.

Final structure looks like:
breach_response/
├── log_dump.txt
├── secure/
│   ├── evidence/
│   │   └── log_dump.txt
│   └── forensics_report.txt
├── reports/
│   └── incident_summary.txt
└── classified.txt

Result: As a result, all the required files have been copied, moved, and updated successfully while restoring the original security permissions.
